About

          
Hi, I'm Aditya.

          
I'm a computer science student learning DevOps by building real things. I like turning slow, manual work into a pipeline that runs the same way every time.

          
This website is my main project: a site that deploys itself. Everything that runs it, from the servers to the firewall rules, is written as code in one repository.
